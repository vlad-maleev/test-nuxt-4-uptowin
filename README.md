# Users Table

A small Nuxt application for browsing a list of users.

[Live demo](https://test-nuxt-4-uptowin.vercel.app/)

## Features

- Search by name or email with debounce
- Filter users by role
- Sort by age and creation date
- Pagination with configurable page size
- Filters, sorting and pagination stored in the URL
- Sticky table header
- Responsive layout
- Light and dark themes

## Tech stack

- Nuxt 4
- Vue 3
- TypeScript
- Tailwind CSS

## Setup

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:3000`.

## Available commands

```bash
npm run build         # Build for production
npm run preview       # Preview the production build
npm run lint          # Run ESLint
npm run format:check  # Check formatting
npm run typecheck     # Check TypeScript types
```
